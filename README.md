# Yandex Weather Service

Учебный консольный клиент к [API Яндекс.Погоды](https://yandex.ru/dev/weather/).

## Запуск

1. Скопируйте `.env.example` в `.env` и подставьте свой ключ.
2. Запустите `Main` из IntelliJ IDEA.

## Примечания

Jar-файлы **намеренно лежат в репозитории**: так проще клонировать и сразу запускать без ручной установки библиотек.
